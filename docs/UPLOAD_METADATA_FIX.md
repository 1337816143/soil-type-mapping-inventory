# 上传元数据修复说明（v1.2.16）

## 两类问题

第一张截图的文件名使用“总体、工作、数据报告”，但未标注“质控意见”。此前将报告类别与文件性质混在一起：类型识别为空，同时仅凭文件名拦截。即使人工填完市、单位、任务，仍缺少未展示的成果类型。另一个缺陷是选文件前手动指定的批量成果类型未保存到新文件。

第二张截图实际文件名为“黄骅市_土壤属性制图_河北玛恩农业科技有限公司_2026年第三次第1批.pdf”。“土壤属性制图”此前未列入属性图识别别名；它不应被改配到土壤类型图。现在识别为土壤属性图，按其他成果通讯录匹配河北玛恩农业科技有限公司，保留第三次第1批。

## 修复后的操作

- 每条上传预览都有“成果类型（必选）”。有问题时只指出真正缺少的字段；已经填好的其他信息保留。确认完整后才上传文件字节。
- 文件名中“土壤属性图/土壤属性制图”和“土壤类型图/土壤类型制图”分别识别；按每条实际成果查询对应通讯录。
- 报告栏目仅归档质控意见。无意见标识的报告类文件先识别类别，管理员必须打开并核对实际内容；确实是意见文件才能点“确认是质控意见”，批量时可以统一确认待核对文件。报告原件应移除，不能为了通过上传把它改名为质控意见。
- 确认绑定本次所选文件的名称、大小、修改时间和路径，重选文件不自动沿用旧确认，允许撤销。明确写有意见标识且元数据完整的文件不再因原来的选择状态而受阻。
- 主动选择的批量类型对本次后选文件及预处理有效；每个文件也可单独改类型或恢复自动识别。
- 上传预处理后仍保留可编辑的预览，不再在失败后只留下文件名文字。
