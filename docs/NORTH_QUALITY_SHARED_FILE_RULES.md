# 北部片区共享质控报告规则

## 文件存储

北部片区综合质控报告采用“一份原文件，多处关联”的方式。文件名中“第三次全国土壤普查成果质控报告”之前列出的地区共享同一份报告，仓库只保存一个物理文件。

## 自动关联范围

综合报告默认同时关联：土壤类型图、土壤属性图、耕地质量等级评价、土壤退化与障碍分析、土特产品土壤适宜性评价、土壤农业利用适宜性评价。土地资源评价与利用报告不自动关联。

## 文件名兼容

系统兼容徐水县/徐水区、满城/满城区、清苑/清苑区、高阳/高阳县、顺平/顺平县、雄安新区本级/雄安新区、承德市本级/承德市等命名差异。“合并区”“市级”“全市”依据同一文件名中相邻的明确地区推断所属城市。

## 上传

管理员可以选择多个报告，也可以直接选择包含报告的 ZIP。ZIP 会先在浏览器中解压，随后逐文件解析。共享报告在上传预览中显示关联任务单元数量和6类成果范围，归档后索引只保留一条物理文件记录，由前端在运行时展开为多个页面关联。
