其他已有合并范围继续只读使用原 `mergeSubDistricts`：石家庄、秦皇岛、邢台、张家口，以及原增强模块中沧州的明确范围；必须在该类成果清单中存在唯一合并任务才使用。独立任务及“井陉县（含矿区）”等明确包含任务优先。

## 展示与上传规则

独立任务先匹配；没有独立条目时检查明确合并成员。成员且单位相符，正常颜色并说明“通讯录按合并区统一分配作业单位，实际成果分开编制，因此按该地区单独质控”；成员但单位不符，红色说明合并区分配单位和当前单位。独立条目及成员证据都没有，则红色说明尚未明确覆盖。

峰峰矿区、丛台区、复兴区为已核实成员；永年区不在上述原文内，不能因为公司相同而推定属于合并区。清单范围说明只解决任务归属，不代替报告正文质控。具有报告表头实质冲突或待人工核对标记的文件仍保留原警示。

用户明确要求删除提示中的排除统计表述；本次更改仅解释通讯录关系，不改统计函数、应交分母、报告原件及已有索引。旧收据只在展示时清理相关语句，历史留痕不重写。
