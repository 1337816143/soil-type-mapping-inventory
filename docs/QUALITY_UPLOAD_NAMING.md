# 质控文件命名与匹配（v1.2.5）

## 单地区单成果

不写公司（自动按该类成果、该地区的原清单匹配）：

```text
所属市_任务单元_成果名称_质控意见_2026年第二次第1批.docx
石家庄市_平山县_土壤类型图_质控意见_2026年第二次第1批.docx
```

写公司（本次导入优先使用文件名中的公司）：

```text
所属市_任务单元_成果名称_公司全称_质控意见_2026年第二次第1批.docx
石家庄市_平山县_土壤类型图_中地科勘察设计有限公司_质控意见_2026年第二次第1批.docx
```

文件格式可用实际 PDF、DOCX 等原格式，不要只改扩展名。公司不是必填项；写时使用全称，推荐下划线单独分隔，不使用不能唯一确定的简称。“合并区”“市级汇总”等任务名称必须带所属市。年份、质控次数、反馈批次分别写清楚；补充材料在批次后加“补充”。

## 匹配优先级

人工明确调整 > 文件名中的明确公司 > 该成果类型与地区的原清单。仅本次导入使用所选公司，绝不回写对照清单。文件名未写公司时，不从旧文件夹名继承公司。

代码保留 `index.html` 的原 masterList 和 `task-unit-mappings.js` 中的 SoilTaskUnitLists：土壤类型图使用其 soilType 清单，其余成果使用现有 other 清单。没有增加、删除或改写清单条目。

实际原清单示例：平山县土壤类型图对应中地科勘察设计有限公司；土壤属性图对应河北湛泸软件开发有限公司。不能把不同成果清单中的这两个正常对应关系当作同一成果的歧义。

## 多地区综合报告

```text
地区甲、地区乙三普成果质控报告_2026年第二次第1批.docx
乐亭县、丰南区三普成果质控报告_2026年第二次第1批.docx
```

这种综合命名沿用目前三类主要成果的规则：土壤类型图、土壤属性图、耕地质量等级评价。每类成果单独确定作业单位，只归档一份原文件。若一份文件明确列出多个成果名称，也为每种成果独立匹配单位。

原来北部28份已登记材料仍沿用权威登记匹配及原始文件名，不为套新模板而重命名。新材料再使用上述模板。

## 看懂上传预览

正常预览逐行显示：成果名称 · 所属市 / 任务单元 → 公司（文件名单位 / 按该类成果清单匹配 / 人工指定）。文件名公司与清单不同时，会提示两者并说明“不改清单”，本次按文件名单位归档。

旧“已识别成果类型与批次，但任务单元仍不唯一”是笼统的归属未确定提示，不表示报告正文有问题。旧代码将两套清单混查，且把所属市和区县同时误认为两个任务，也会触发它。现改为具体说明缺少任务单元、同名地区、多个公司、所属市与地区矛盾等原因；需要时再使用“显示人工调整”，调整后不会被自动刷新覆盖，点击“恢复自动模式”可重新按文件名与原清单识别。

## v1.2.6 清单外地区

```text
邯郸市_永年区_土特产品土壤适宜性评价_河北省农林科学院农业资源环境研究所_质控意见_2026年第二次第1批.docx
```

完整命名解析为候选，预览保留全部字段；核对后点击“确认按文件名归档”，再填写管理员密码上传。清单外任务必须提供单位全称；换文件、改变批次或归属须重新确认。

清单外任务及单位不一致的成果在展示区标红，悬停追加“与作业单位通讯录不一致”。清单外文件不计入原清单收缴进度，不修改通讯录或统计分母。
