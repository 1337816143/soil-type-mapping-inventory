# 第三次全国土壤普查参考资料

本目录用于集中保存第三次全国土壤普查成果编制、验收与质量控制参考资料。

## 存储规则

- 资料按原压缩包目录层级解压保存，不再把整包 ZIP 拆成随机二进制分块。
- 单个文件不超过 GitHub 普通仓库限制时，保持原文件不变。
- 仅对超过单文件限制的资料进行拆分，拆分必须按照连续页、连续章节、连续幻灯片或连续工作表进行，并在文件名后添加“第X部分”及内容范围后缀。
- Office 临时锁文件（`~$` 开头）可不在网站目录中展示。

## 当前超限文件

原文件 `2026.05.12河北省三普土壤属性制图专题培训.pptx` 超过 100 MB，已按原始幻灯片顺序和连续章节拆分为四部分：

1. 第1部分：土壤属性制图，第1—26页；
2. 第2部分：土壤农业利用适宜性评价——区县级评价，第27—43页；
3. 第3部分：土壤农业利用适宜性评价——制图综合与省市级汇总，第44—61页；
4. 第4部分：耕地质量等级评价，第62—82页。

## 后续导入

网站“参考文件”标签页和各成果行均提供“管理员导入”入口。管理员可：

- 选择已有目录；
- 在已有目录下新建子目录；
- 上传单个或多个文件；
- 选择整个文件夹并保留层级；
- 上传 ZIP，由浏览器解压后按内部层级写入仓库。

每次管理员导入只在所有文件上传完成后生成一个 Git 提交，并一次性更新 `main`。
